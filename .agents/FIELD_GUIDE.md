# 已验证现场经验

## FG-20261028-01：Bing 尺寸后缀必须实测

- 适用范围：2026-10-28 Bing 中国区 HPImageArchive 当前图片。
- 现象：看似合理的尺寸后缀可能返回 404，导致列表只有占位背景。
- 已验证结论：UHD=3840x2160；1920x1080、1920x1200、1080x1920 匹配；2560x1440 和列表最初使用的 960x540 未能提供可用图片。
- 处理方法：列表请求已验证的 1920x1080，在设备上采样解码成小图；保存时验证真实尺寸，不能凭 URL 命名。
- 证据：Bing 实际请求、MainActivity.photo、DeviceChecks 及设备取回文件像素检查。
- 失效条件：Bing 接口或图片处理服务变化后需要重新验证。
